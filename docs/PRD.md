# 📚 luvTALK 产品需求文档 (PRD)

**项目名称 (Project Name):** luvTALK  
**版本 (Version):** 1.0.0 (MVP)  
**日期 (Date):** 2025年11月12日  
**目标用户 (Target Users):** 初级至中级粤语和英语学习者

---

## 1. 产品概述 (Product Overview)

luvTALK 是一款基于 **PWA (Progressive Web App)** 和 **AI 驱动**的实时语言学习应用。通过模拟真实场景的对话练习，并提供即时反馈和文化解释，旨在提供沉浸式的学习体验。

**核心理念：** 专注于对话实践和有效反馈，通过 luvTALK (Love to Talk) 让语言学习更有趣。

---

## 2. 核心功能与场景 (Core Features and Scenarios)

### 2.1. 核心场景：AI 实时对话 (Core Scenario: AI Real-time Conversation)

**2.1.1 场景选择**
- **描述：** 用户选择练习语言 (粤语/英语) 和对话场景 (e.g., 餐厅点餐、问路)
- **技术栈依赖：** Frontend/Backend

**2.1.2 语音输入**
- **描述：** 用户通过 PWA 界面按下并说话
- **技术栈依赖：** React + Ionic

**2.1.3 实时转写**
- **描述：** 用户的语音被实时或快速转写成文本并显示
- **技术栈依赖：** Google Cloud Speech-to-Text (ASR)

**2.1.4 AI 导师回复**
- **描述：** AI 导师根据对话上下文生成回复文本
- **技术栈依赖：** Google Gemini API (LLM)

**2.1.5 原生语音输出**
- **描述：** AI 导师的回复以自然、原生的语音播放
- **技术栈依赖：** Google Cloud Text-to-Speech (TTS)

### 2.2. 关键辅助功能 (Key Supporting Features)

**2.2.1 即时语法反馈**
- **描述：** AI 对用户最近的发言进行语法、发音或风格修正，并提供解释
- **触发方式：** 对话进行中（LLM 结构化输出）

**2.2.2 文化解释**
- **描述：** 提供对话中涉及的文化背景或习俗的简短解释
- **触发方式：** 用户点击提示图标 或 LLM 自主触发

**2.2.3 翻译功能**
- **描述：** 用户可随时点击 AI 或自己的某句话，显示目标语言和母语翻译
- **触发方式：** 用户点击/长按对话气泡

---

## 3. 学习本功能 (Learning Notebook Feature)

为了支持学习和回顾，增加"学习本"功能，用于记录和收藏关键学习内容。

**3.1.1 对话收藏**
- **描述：** 用户可以将整段对话（包括 AI 导师的反馈和文化解释）保存到学习本中
- **数据存储依赖：** PostgreSQL + Prisma

**3.1.2 单句收藏**
- **描述：** 用户可以单独收藏对话中的任意一句精彩或难点语句
- **数据存储依赖：** PostgreSQL + Prisma

**3.1.3 笔记分类**
- **描述：** 学习本支持按语言 (粤语/英语) 和自定义标签进行分类和筛选
- **数据存储依赖：** PostgreSQL + Prisma

**3.1.4 回顾模式 (MVP)**
- **描述：** 学习本界面简洁展示收藏的对话或语句列表，用户可以点击查看完整内容
- **数据存储依赖：** Frontend (React/Ionic)
