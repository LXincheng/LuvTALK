# 成就与等级系统设计文档

> 目标：匹配最新 UI（成就殿堂 / 等级）展示，提供可扩展的数据结构与统计口径。

## 1. 需求拆解

| 模块     | 展示内容                        | 需要的数据          | 说明              |
| -------- | ------------------------------- | ------------------- | ----------------- |
| 成就卡片 | 标题、描述、图标、进度、稀有度  | 成就定义 + 用户进度 | 支持锁定/解锁状态 |
| 等级卡片 | 等级、称号、图标、升级进度      | 等级定义 + 用户 XP  | 体现成长路径      |
| 统计概览 | 解锁数、当前等级、总 XP、完成率 | 聚合数据            | 用于顶部概览      |

## 2. 表结构设计（逻辑）

| 表              | 作用         | 关键字段                                                                 | 说明          |
| --------------- | ------------ | ------------------------------------------------------------------------ | ------------- |
| Achievement     | 成就模板     | code, title, description, icon, color, rarity, targetValue, targetMetric | 可热更新      |
| UserAchievement | 用户成就进度 | userId, achievementId, progress, unlockedAt                              | 一人一条      |
| LevelDefinition | 等级模板     | level, title, icon, color, minXp                                         | 等级阶梯      |
| UserLevel       | 用户等级进度 | userId, levelId, currentXp                                               | 当前等级/经验 |

## 3. 规则与计算

| 计算项     | 口径                                        |
| ---------- | ------------------------------------------- |
| 成就完成率 | 已解锁数量 / 成就总数                       |
| 当前等级   | `UserLevel.levelId` 指向的 LevelDefinition  |
| 升级进度   | `(currentXp - minXp) / (nextMinXp - minXp)` |
